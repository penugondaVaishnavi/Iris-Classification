# Iris Classification

This project is part of the Alfido Tech Machine Learning Internship.

## Objective
To classify iris flowers into different species using Machine Learning techniques.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Algorithm Used
- Logistic Regression

## Project Workflow
1. Load Iris dataset
2. Perform data analysis
3. Visualize dataset
4. Train Logistic Regression model
5. Evaluate model accuracy

## Result
The model successfully classified iris flowers with high accuracy.
